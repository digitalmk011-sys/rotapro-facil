# RotaPro Fácil V1.3.1 — Endereços limpos

- Ao importar Excel, padroniza R / R. para Rua, Av para Avenida, Tv para Travessa e outras abreviações.
- Correção explícita: Acoiara → Acopiara.
- Mantém apenas logradouro e número, removendo complementos depois do número.
- Endereços adicionados manualmente recebem a mesma limpeza.
- Nomes de ruas desconhecidos não são alterados por adivinhação.
- A cidade continua armazenada separadamente para auxiliar localização.
- Não modifica entregas previamente salvas: para aplicar a limpeza a elas, importe a planilha novamente.
- Coordenadas existentes na planilha são preservadas; endereços incorretos devem ser conferidos antes da entrega.
